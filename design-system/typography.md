# Typographie

## Titres
Les pages HTML observées chargent Bricolage Grotesque via Google Fonts, graisses 500 et 800, axe optique variable. La pile de repli des titres inclut Georgia/serif. Utiliser principalement la graisse 800 pour les titres forts.

## Corps
Le site emploie une pile sans-serif système. Pile de référence recommandée : system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif. Cette centralisation est une recommandation ; ne signifie pas que chaque page utilise déjà exactement cette chaîne.

## Échelle recommandée

| Rôle | Taille | Graisse | Interligne |
|---|---|---|---|
| H1 héro | clamp(2.4rem, 7vw, 5.8rem) | 800 | 0.98–1.08 |
| H1 éditorial | clamp(2rem, 5vw, 3.6rem) | 800 | 1.05–1.15 |
| H2 | clamp(1.8rem, 4vw, 3rem) | 800 | 1.05–1.2 |
| H3 | 1.2–1.5rem | 700–800 | 1.15–1.3 |
| Corps | 1–1.0625rem | 400 | 1.55–1.75 |
| Intro | 1.1–1.25rem | 400–500 | 1.5–1.65 |
| Label | 0.8–0.95rem | 600–700 | 1.3–1.5 |
| Métadonnée | 0.75–0.875rem | 400–600 | 1.4–1.6 |

## Règles
Un H1 descriptif par page ; H2 pour les sections, H3 pour sous-parties. Garder une largeur de lecture de 60–70 caractères sur bureau. Prévoir le retour à la ligne des mots longs et URL sur mobile. Ne pas bloquer le zoom. Le site doit rester lisible si Google Fonts échoue.
